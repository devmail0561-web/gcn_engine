BUG CRITIQUE À CORRIGER EN PRIORITÉ
-------------------------------------
training/train.py:97 contient :
    n_rel = 22 if bidirectional else len(RELATION_TYPES)

au lieu de 24 → corruption silencieuse du modèle.
CORRECTION : remplacer par   2 * len(RELATION_TYPES)
À faire avant tout ajout de RelationType.

UPOS_TAGS / UD_DEP_RELS / UD_TENSE/ASPECT/MOOD
------------------------------------------------
- Pas de couplage Rust enum (strings directes).
- Contrainte : valeurs définies par le standard Universal Dependencies.
  Extensions légitimes = sous-types UD que certains parseurs produisent
  (ex: nsubj:pass, obl:tmod, Asp=Hab).
- Toute modification change d_clause → shapes MLP → checkpoint invalidé.
- Chemin : uniquement constants.py + réentraînement.
- Le FeatureVocabulary est sérialisé dans le .npz (clé _vocab_json),
  l'incompatibilité est détectée au chargement (ValueError).
